# Brief 261 — split three stdlib catalog files (file-size hygiene)

## Goal

Three stdlib catalog files in the split-plan range (AGENTS.md) are each
broken into responsibility-based sibling files, each exporting one
sub-const. PURE REORGANIZATION: the set of registered builtins, their
attributes, messages, summaries, and the generated reference are all
UNCHANGED. `docs/reference/builtins.md` regenerates BYTE-IDENTICAL.

- `catalog/strings.rs` (27.5 KB, 79 entries) → 3 files.
- `catalog/structure.rs` (25.4 KB, 50 entries) → 2 files.
- `catalog/associations.rs` (21.0 KB, 37 entries) → 2 files.

## The splits (contiguous, order-preserving; cut at family boundaries)

Keep every entry verbatim and in its current relative order within its
run. Do not edit any entry's text, attributes, or messages. Use SIBLING
files in `crates/rum-stdlib/src/catalog/` (NOT subdirectories) so the
existing `use super::message_templates::*;` and `use crate::…;` imports
resolve unchanged.

### strings.rs → `STRING_CORE_BUILTINS` + two new siblings

- `catalog/strings.rs` keeps `STRING_CORE_BUILTINS` = `StringJoin`
  through `Row`.
- NEW `catalog/strings_text.rs` `STRING_TEXT_BUILTINS` = `StringRiffle`
  through `Diff`.
- NEW `catalog/strings_match.rs` `STRING_MATCH_BUILTINS` = `Characters`
  through `StringFreeQ`.

### structure.rs → `STRUCTURE_CORE_BUILTINS` + one new sibling

- `catalog/structure.rs` keeps `STRUCTURE_CORE_BUILTINS` = `FullForm`
  through `Transpose`.
- NEW `catalog/structure_ordering.rs` `STRUCTURE_ORDERING_BUILTINS` =
  `DeleteDuplicates` through `Construct`.

### associations.rs → `ASSOCIATION_CORE_BUILTINS` + one new sibling

- `catalog/associations.rs` keeps `ASSOCIATION_CORE_BUILTINS` =
  `Association` through `KeySortBy`.
- NEW `catalog/associations_transform.rs` `ASSOCIATION_TRANSFORM_BUILTINS`
  = `AssociationMap` through `DeleteMissing`.

Each NEW sibling file needs the same `use` imports the source file has,
plus any local `const` its moved entries reference (e.g. strings.rs
defines `const ATTR_PROTECTED` at its top — copy the ones the moved
entries use). The compiler enforces completeness; add exactly what is
referenced, nothing more.
