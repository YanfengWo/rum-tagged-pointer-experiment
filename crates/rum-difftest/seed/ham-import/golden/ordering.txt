# Tests canonical ordering, set semantics, and Order function.
# Sort

# Union
Union[{b, a, b}] ||| {a, b}
Union[{1, 2, 2, 3}] ||| {1, 2, 3}
# Intersection
Intersection[{3, 1, 2}, {2, 3, 4}] ||| {2, 3}
Intersection[{1, 2, 3}, {2, 3, 4}] ||| {2, 3}
# Complement
